Everything below is **synthetic algebra**, not a generated response or a selected evaluation success. The text fixture is `2*(3+4)` for numbers `[2,3,4]`, target14. The strict verifier uses Fraction arithmetic and an AST allowlist, enforces number multiplicities, and accepts the entire expression only. It does not extract, repair or judge prose. Intermediate fractions are legal; unary signs, powers, decimals, fences and equations are not.

`prepare_targets('ppo_zero', records)` writes FP32 zeros for every real old value and calls the same `rollout_targets` as learned PPO. The fixed-zero role tuple is actor/reference; there is no critic model, head or optimizer.
