The root license contains the canonical Apache License, Version 2.0 text. The [Qwen upstream notice](../notices/Qwen-LICENSE) is preserved unchanged with [source references](references/SOURCES.md); it is not a blanket license grant for all project code or data.

The intended public repository is `yangqi0/petitzero`; the first-release scope is described below. The `release_preparation` entry in provenance records the earlier packaging stage, not the current publication state of this repository.

The first public release includes code, synthetic prompt-only engineering fixtures, compact aggregate/per-question success counts and existing figures. It excludes exact private historical prompts, private SFT demonstrations, model adapters, base weights, optimizer states and private engineering evidence. Any later expansion of this scope requires a separate owner decision. The RunPod network volume remains retained; this code package is not a weight backup.
