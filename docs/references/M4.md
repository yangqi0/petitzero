# M4 source and method attribution

Author: Yang Qi.

M4 uses the supplied final_metrics.py and19 pure CPU tests, the unchanged PetitZero Fraction verifier, and a narrowly copied inference path from the bound M3 driver. Qwen2.5-1.5B-Instruct, Transformers, PEFT, PyTorch, tokenizers and NumPy identities/versions are recorded in the runtime and bindings. No dependency upgrade or external retrieval was performed.

The owner package supplies these explanatory references; they are not project-performance evidence:

- [Stable Baselines3 explained_variance implementation](https://stable-baselines3.readthedocs.io/en/master/_modules/stable_baselines3/common/utils.html): the formula omits constant bias.
- [High-Dimensional Continuous Control Using Generalized Advantage Estimation](https://arxiv.org/abs/1506.02438): methodological background for historical M3, not a claim to reproduce that paper's experiments.

Upstream citations do not imply coauthorship or affiliation. Yang Qi remains the sole project author.
