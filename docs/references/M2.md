# M2 method and software attribution

Project author: Yang Qi. Method/software attribution is separate from authorship.

The owner supplied these references in `PETITZERO_M2_ONLINE_RFT_PACKAGE/reference/EXTERNAL_SOURCES.json`; this offline execution does not claim a fresh web review.

- DeepSeekMath, section 5.2 and Appendix A.1: https://arxiv.org/html/2402.03300v3 . Background for online rejection-sampling fine-tuning; it does not guarantee a particular PetitZero result.
- TRL GRPO Trainer: https://huggingface.co/docs/trl/grpo_trainer . Background on algorithm/normalization distinctions and training/inference likelihood mismatch. Neither M1B nor M2 is an installed-TRL run.
- PyTorch 2.8 numerical accuracy: https://docs.pytorch.org/docs/2.8/notes/numerical_accuracy.html . Mathematically equivalent operations can differ with layout/path. This is not a diagnosis of M1B's particular 0.350719 action-logp discrepancy, which remains an observed limitation.
- Qwen/Qwen2.5-1.5B-Instruct: https://huggingface.co/Qwen/Qwen2.5-1.5B-Instruct . Only local revision 989aa7980e4cf806f80c7fef2b1adb7bc71aa306, original tokenizer/template and M1A SFT adapter are loaded initially. Upstream model card/license remain intact.
- PyTorch, Transformers, PEFT, Accelerate, safetensors, NumPy and psutil retain their upstream attribution. Versions are inherited unchanged from the fixed environment; no package is installed or upgraded.

`src/petitzero/rft.py` is a byte-identical copy of the supplied pure RFT helper. Its 15 tests have only their import path adapted. `rft_runtime.py` adds the production skip controller also exercised with toy optimizers. The new driver copies stable M1B generation/model-loading profile code as text into a new run-local implementation; it does not import or execute the historical training driver. Existing reward/action-mask helpers remain unchanged.
